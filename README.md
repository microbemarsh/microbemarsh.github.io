# Austin Marshall — Academic Portfolio

Personal academic portfolio, research archive, and blog for Austin Marshall.

The site uses [Astro](https://astro.build/) and the MIT-licensed [Academic Portfolio Astro](https://github.com/rubzip/academic-portfolio-astro) template. Almost all personal content is stored as Markdown under `src/content/`.

## Update the site

See [UPDATING.md](UPDATING.md) for concise instructions covering:

- the prepared University of Florida position;
- blog posts;
- publications;
- research projects;
- talks and teaching;
- biography, experience, and education.

## Local development

Node.js 22.12 or newer is required.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

GitHub Actions deploys the generated static site to GitHub Pages.
